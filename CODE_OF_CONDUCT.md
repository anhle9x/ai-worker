# Code of conduct

This project is a place to build something useful together. Everyone who takes part, in issues, pull requests or messages, agrees to:

- **Be respectful.** Discuss the work, not the person. No insults, harassment or discrimination of any kind.
- **Be patient with newcomers.** Many people here are not developers; explain plainly.
- **Keep other people's data private.** Never post real names, emails, screenshots of real dashboards or company numbers, yours or anyone else's.
- **Report security problems privately**, as [SECURITY.md](SECURITY.md) explains.

If someone does not follow this, message the maintainer on Telegram at [t.me/anhle9x](https://t.me/anhle9x). Reports are kept private. The maintainer may edit or remove comments, close issues or block people who break these rules.
