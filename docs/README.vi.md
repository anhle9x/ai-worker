# Tài liệu

Toàn bộ tài liệu AI Worker, xếp theo mục đích. Mỗi tài liệu có một file tiếng Anh và một file tiếng Việt (`.vi.md`).

| Phần | Tài liệu | Dành cho |
|---|---|---|
| **I. Đặc tả yêu cầu** | [ARCHITECTURE.vi.md](ARCHITECTURE.vi.md), mục 1: mục tiêu, phạm vi, người dùng, chức năng bắt buộc, giới hạn, dữ liệu lưu | Mọi người |
| | [menu-bar-spec.vi.md](menu-bar-spec.vi.md): biểu tượng thanh menu | Lập trình viên |
| | [chrome-extension-spec.vi.md](chrome-extension-spec.vi.md): tiện ích trình duyệt | Lập trình viên |
| **II. Thiết kế hệ thống** | [ARCHITECTURE.vi.md](ARCHITECTURE.vi.md), mục 2 tới 6: các thành phần, luồng xử lý chính, lựa chọn thiết kế, giới hạn đã biết | Lập trình viên, quản trị |
| | [DATA-MODEL.vi.md](DATA-MODEL.vi.md): thiết kế dữ liệu, lưu gì, ở đâu, bao lâu | Lập trình viên, quản trị |

| | [THIRD-PARTY.md](../THIRD-PARTY.md): code bên ngoài và giấy phép (tiếng Anh) | Quản trị, pháp chế |
| **IV. Hướng dẫn sử dụng** | [USER-GUIDE.vi.md](USER-GUIDE.vi.md): nhân viên, quản lý, quản trị | Mọi người |
